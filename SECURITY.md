# Security reports

Report suspected data exposure, backup failures or permission bypasses to the repository owner privately. If GitHub private vulnerability reporting is enabled, use the Security tab. Otherwise contact the owner privately before posting details in an issue.

Include the app version, Android version, reproduction steps and a sanitized sample. Never upload real SMS/email contents, OTPs, banking credentials, a live database or a personal backup.

The current release is a development build. See [Privacy](docs/PRIVACY.md) and [Testing](docs/TESTING.md) for implemented boundaries and unverified device behaviour.
